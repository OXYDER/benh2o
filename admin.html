Comment publier tes changements

  1. Fais tes modifications ci-dessus (elles sont sauvegardées automatiquement dans ce navigateur pendant que tu travailles).
  2. Clique Télécharger zones.json et/ou Télécharger contact.json selon ce que tu as changé.
  3. Remplace assets/zones.json et/ou assets/contact.json dans le projet par les fichiers téléchargés.
  4. Commit et push sur GitHub, puis sur le NAS : ./deploy.sh.

⚠️ Cette page n'est protégée par aucun mot de passe — n'importe qui connaissant l'adresse /admin.html peut la modifier (les changements restent locaux à leur navigateur tant qu'ils ne téléchargent pas les fichiers). Pour une vraie protection, ajoute une liste d'accès (utilisateur/mot de passe) sur ce chemin dans Nginx Proxy Manager.
