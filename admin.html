Régions, MRC et municipalités couvertes

Ajoute, renomme ou retire des secteurs. Tes changements sont sauvegardés automatiquement dans ce navigateur (brouillon) — pour les rendre visibles sur le site public, télécharge le fichier zones.json ci-dessous et remplace-le dans le projet (voir les instructions en bas de page).

Comment publier tes changements

  1. Fais tes modifications ci-dessus (elles sont sauvegardées automatiquement dans ce navigateur pendant que tu travailles).
  2. Clique Télécharger zones.json — le fichier se télécharge sur ton ordinateur.
  3. Remplace assets/zones.json dans le projet par ce fichier téléchargé.
  4. Commit et push sur GitHub, puis sur le NAS : ./deploy.sh.

⚠️ Cette page n'est protégée par aucun mot de passe — n'importe qui connaissant l'adresse /admin.html peut la modifier (les changements restent locaux à leur navigateur tant qu'ils ne téléchargent pas le fichier). Pour une vraie protection, ajoute une liste d'accès (utilisateur/mot de passe) sur ce chemin dans Nginx Proxy Manager.
